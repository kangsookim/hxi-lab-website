HXIL master asset set

Geometry rules:
- H, X, and the combined IL block have matched visual widths: H = 140 units, X = 145 units, IL = 145 units (approximately 1:1:1).
- H, X, I, and L share exactly the same cap height.
- L horizontal stroke ends at x=474; it is intentionally shortened for balanced H:X:IL proportions.
- X geometry and cyan-blue-purple gradient are unchanged.
- No subtitle.
- No LAB word; primary wordmark is HXIL only.
- Light = navy letters on transparent background.
- Dark = white letters on transparent background.
- X mark/icon geometry is shared across all assets.
